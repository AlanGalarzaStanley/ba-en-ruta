## Estrategia

1. **Turista:** 45–90 s, una idea, una imagen fuerte, un tip.
2. **Chofer:** mismo guion escrito (ayuda-memoria); no depende del video.
3. Producción nueva: solo cuando el propietario grabe; no contratar edición externa desde este flujo.
4. Licencias: preferir material propio o canales oficiales (visitarg, clubes, GCBA).
